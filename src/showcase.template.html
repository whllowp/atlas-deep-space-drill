03 / DESIGN TOKENS

一套可复用的座舱视觉语言

颜色、字体、切角与发光都来自同一套 token；新增面板只要复用 `.panel` / `--cut` / 状态色。

Palette

深空青为默认主色，琥珀用于能量/警示，品红用于敌对与 Boss，绿色只表示恢复与完成。

CYAN / 5EF2FF
AMBER / FFC857
MAGENTA / FF2E88
GREEN / 57FFB0
VIOLET / 9A6BFF

Type & Tokens

标题用 Bahnschrift / DIN，指标与标签用等宽字体；所有数字使用 tabular-nums 对齐。
