## 本轮验收（6–10）

- **C2 COMMS**：左侧通话记录滚动/打字机输出，波形动画，`LINK / ALERT / END` 状态；阶段公告、出牌、结算都会写入。
- **仪表盘**：战术终端右侧新增 240×240 雷达，含扫描扇区、节点绿/黄/红点、敌对红点与 `RADAR / HOSTILE` 计数；P1/P2/P3 敌情数量不同。
- **视觉系统**：`--cut` / `--cut-lg` 切角 token、面板四角括线、相位 LED、链路状态灯；阶段条进入 annunciator 状态。
- **结算复盘**：S 评级虚线印章、积分滚动、本局出牌序列 chip、MVP 统计、`复制战报`（剪贴板，含降级方案）。
- **响应式**：2560×1440 与 3840×2160 无溢出；1280×720 自动隐藏 C2 面板并上移 Boss 血条；≤1180 隐藏左栏与击杀播报；电影模式完全隐藏座舱/HUD。
- 1920×1080 / 1366×768 / 2560×1440 / 3840×2160 / 1280×720 / 1024×768 均无控制台报错。

## 本轮验收（1–5）

- 大厅右下出现 OPS DECK：5 张卡、能量条、四盏 caution 灯、C2 通讯条。
- 按 `1`–`5` 或点击出牌：能量下降、卡面进入冷却、日志与通讯回执、积分与连击增加。
- 5 张卡均接入 `sim.playTactic()`，有实际指标/积分效果；`封禁 IP` 会清空当前敌舰并产生粒子爆发。
- 右侧新增 **THREAT INTENT**：P1 `SYN FLOOD` / P2 `DB LOCK` / P3 `OMNI BEAM`，显示倒计时与进度条，P3 切红色告警态。
- `Shift+1/2/3` 跳阶段；`C` 进入电影模式时座舱和手牌随 HUD 一起隐藏。
- 1920×1080 / 1366×768 均无页面溢出，控制台无报错。
